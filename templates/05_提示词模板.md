# 05 提示词模板（七段式，逐段填）

## A. 生图提示词（每张一版）
```
<画风锁>
<角色锁（含服色 HEX、配件位置）>
<景别与机位>，<主体与朝向>，<构图（母题线穿过下三分之一）>，
<光源与配色>，<首帧要出现的关键物件（后续动作要用到的都在画面里）>，
焦点准确，主体清晰，画面中没有任何文字、水印、标志。
```

## B. 生视频提示词（首帧图 + 这段）
```
<画风锁>
<角色锁（简版：年龄/服色/配件）>
整段 <N> 秒，<景别>，<机位>，<运镜；不动就写"不推不拉不摇，不切镜">
【逐秒】0–<x>s：画面完全静止，和首帧一模一样。
           <x>–<y>s：<谁做什么，表情怎么变，手放哪、不能碰什么，往画面哪边>
           最后 0.3 秒：所有人完全停住，画面与尾帧一致。
声音：只有 <看得见原因的声音>。人物不说话。
约束：画面里一直只有首帧这几个人和这些东西，一镜到底，无文字。
```

## C. 常见坑与写法对照（按需加）
| 坑 | 写法 |
|---|---|
| 人群同步动作 | 写清先后："甲先…过一秒乙…最后丙…"，首帧别摆同姿势 |
| 东西凭空出现 | 只用首帧已有的东西；动作要用的道具首帧就画上 |
| 方向反 | 按画面写："朝画面左走" |
| 一镜换光 | 拆成"人物从影里走进光"，光源不动 |
| "不要…"无效 | 改正面写："画面里一直只有这两个人" |
| 雨/帽子/纹身消失 | 首帧和尾帧都画上 |
| 手部崩坏 | 手部动作 ≤1 个，且写清原因与位置 |
